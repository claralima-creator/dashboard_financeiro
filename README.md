# 📊 Dashboard Financeiro

Dashboard financeiro desenvolvido como projeto prático de estudos em JavaScript.

O projeto permite visualizar e organizar transações financeiras, separando receitas e despesas e apresentando um resumo do saldo disponível.

## 🚀 Funcionalidades

* Adicionar novas transações
* Visualizar receitas e despesas em uma tabela
* Filtrar transações por:

  * Todas
  * Receitas
  * Despesas
* Excluir transações
* Calcular automaticamente:

  * 💰 Entradas
  * 💸 Saídas
  * 📊 Saldo líquido
* Formatação dos valores em Real brasileiro (R$)

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
